🚀 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Generate models:
   cd /Users/melion/Documents/bible
   flutter pub run build_runner build --delete-conflicting-outputs

2. Add to GoRouter (main.dart):
   GoRoute(
     path: '/lockscreen-verses',
     builder: (context, state) => const LockscreenVersesScreen(),
   ),
   GoRoute(
     path: '/root-access',
     builder: (context, state) => const RootAccessScreen(),
   ),

3. Update settings_screen.dart:
   ListTile(
     title: const Text('Lock Screen Verses'),
     onTap: () => context.push('/lockscreen-verses'),
   ),

4. Build:
   flutter build apk --release

5. Test:
   adb install -r build/app/outputs/flutter-apk/app-release.apk

📊 ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User Action (Lock Screen Verses Screen)
         ↓
RandomVersesNotifier (Riverpod State)
         ↓
RandomVersesRepository
         ↓
BibleRepository (fetch verses)
RandomVersesLocalSource (cache)
         ↓
[10 Random Verses Loaded]
         ↓
WallpaperApplier (static wallpaper)
         ↓
With Root: LockScreenReceiver + RootAccessService
         ↓
Automatic verse rotation on lock/unlock

🔐 ROOT FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RootAccessScreen
       ↓
Click "Request Root Access"
       ↓
RootAccessService.requestRoot()
       ↓
Runtime.exec("su")
       ↓
Magisk/SuperSU dialog prompts user
       ↓
User grants or denies
       ↓
isRooted() = true/false
       ↓
If true: LockScreenReceiver activates
         Listen for ACTION_SCREEN_OFF → rotate verse
         Listen for ACTION_USER_PRESENT → display verse
